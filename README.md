# 🛒 Zepto SQL Analytics Dashboard

## 📌 Project Overview

This project analyzes Zepto grocery product data using PostgreSQL and Power BI. It demonstrates data cleaning, SQL analysis, KPI creation, and dashboard development to derive business insights.
